A complete top-down stealth heist built on the proven stealth HUD: a header with level, objective and shift timer, sidebars tracking detection, alarm, visibility, noise, loot and per-guard state, plus a mission log, legend and controls. This v5 pass upgrades the visual read of every encounter with radial-gradient vision cones that fade softly at their edges, and stronger, broader lamp pools that make light-versus-shadow a clear, readable stealth cue. Original procedural art, no external assets, no network requests.

## Run it

```bash
node main.ts
```

This copies `game/` and `screenshots/` into the output directory (set `MAKEFUN_OUTPUT_DIR`, default `/output`) and writes `dossier.json`, reporting its byte size.
